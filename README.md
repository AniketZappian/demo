# RedirectMax console demo

A clickable demo of a LeadScience portal with a RedirectMax console section. It uses sample data only and has no backend.

```bash
cd app
npm install
npm run dev
```

Open the Local or Network URL it prints, then click **RedirectMax** in the sidebar. Add `?as=super-admin`, `?as=approver`, `?as=operator`, `?as=config-editor` or `?as=viewer` to the URL to start as that role.

`npm test` runs the tests, `npm run build` builds, `npm run lint` lints.
